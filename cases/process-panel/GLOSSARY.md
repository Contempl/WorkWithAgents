# Process Panel

A local tool for managing projects from one browser interface.

## Language

**Panel**:
The local application that lists **Projects** and provides controls for their
execution and output.
_Avoid_: dashboard or task manager as synonyms for Panel.

**Project**:
A named code folder registered in the **Panel** with a command used to launch it.
_Avoid_: process, server, or terminal as synonyms for Project.
