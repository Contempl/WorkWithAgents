# Панель проектов

Первый рабочий срез по [тикету #2](https://github.com/Contempl/WorkWithAgents/issues/2): регистрация Project в текущем сеансе, запуск команды из указанной папки, просмотр stdout/stderr и остановка дерева процессов.

Нужны Windows 10 или новее, Go и Node.js/npm в PATH. Реализация проверена с Go 1.27.4, Node.js 24.13.1 и установленным Microsoft Edge. Сервер написан на Go, интерфейс — на React и TypeScript, сборка интерфейса — Vite.

Из `cases/process-panel/` один раз установите зависимости:

```powershell
npm ci
```

Команда запуска и адрес заданы в [AGENTS.md](AGENTS.md#startup-contract). `npm start` собирает интерфейс и Go-сервер и запускает Panel. При занятом адресе запуск завершится с ошибкой, существующий сервис продолжит работать.

Для ручной проверки добавьте проект:

- Название: `Учебный сайт`.
- Папка: абсолютный путь к `cases/process-panel/examples/learning-site` в этом репозитории.
- Команда: `node server.mjs`.

Нажмите «Запустить», дождитесь вывода о готовности и откройте [учебный сайт](http://127.0.0.1:4100). Команда `node server.mjs 4200` использует другой порт. Если Node.js отсутствует в PATH, укажите полный путь к `node.exe` в двойных кавычках.

Нажмите «Остановить»: сайт должен перестать отвечать, вывод останется виден. Учебная программа запускает HTTP-сервер дочерним процессом; остановка проверяет всё дерево. Команды выполняются через `cmd.exe /d /s /c`, stdout и stderr объединяются. «Работает» означает наличие активной программы, готовность произвольного приложения Panel не определяет.

Обновление страницы сохраняет текущие проекты и их состояние. После выключения Panel список и вывод исчезают: постоянное хранение относится к #3. Редактирование и удаление регистраций также остаются за пределами #2. Закрытие вкладки оставляет Go-сервер работать. Для выключения используйте Ctrl+C в терминале запуска.

Проверки:

```powershell
npm run typecheck
npm test
```

`npm test` собирает приложение и выполняет системные проверки через настоящий Edge и учебные процессы. Edge должен быть установлен; браузер отдельно не скачивается. Проверки занимают адрес Panel и свободные временные учебные порты. Если адрес Panel уже занят, сначала завершите свой экземпляр обычным способом. Проверяющий стенд завершает только созданные им процессы.

Отдельная первичная Windows-проверка сохранена в локальной ветке `prototype/process-panel-windows-job`, коммит `9da8526`, каталог `cases/process-panel/windows-job-probe`. Она проверяет обычную остановку, аварийное завершение управляющей программы и сохранность отдельного контрольного HTTP-сервера. Используются Job Objects с назначением при создании процесса и завершением группы при закрытии последнего дескриптора. Не проверены программы, которые делегируют запуск внешним службам или планировщику Windows.
